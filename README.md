## Technologies

- **HTML5** — structure sémantique, balises meta SEO et Open Graph, données structurées JSON-LD
- **CSS3** — variables CSS, Flexbox et Grid, glassmorphism, thème clair/sombre, responsive (4 paliers)
- **JavaScript (vanilla)** — aucun framework ni bibliothèque

### Fonctionnalités

- Fond animé « matrix » en `<canvas>`
- Navigation collante avec fond flouté et indicateur de section active
- Menu burger sur mobile
- Effet machine à écrire sur le titre principal
- Animations d'apparition au scroll (`IntersectionObserver`)
- Compteurs animés et barres de progression des compétences
- Mode clair / sombre mémorisé dans le `localStorage`
- Formulaire de contact avec validation JavaScript
- Accessibilité : lien d'évitement, attributs ARIA, navigation clavier, `prefers-reduced-motion`

## Installation locale

```bash

cd Personal-Portfolio
```

Il suffit ensuite d'ouvrir `index.html` dans un navigateur : aucune dépendance ni compilation.
